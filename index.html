How I work

  1. Discovery

    We talk through your goals, audience, content and timeline so the site is built around what you actually need.

  2. Structure and design

    I plan the page structure and visual direction, then share it with you for feedback before building in full.

  3. Build

    I write clean, semantic, responsive code and test navigation, links and layouts on different screen sizes.

  4. Review and refine

    You review the result and request changes. I fix issues and polish the details.

  5. Launch and handover

    I help publish the site and hand over organized files with simple notes for future edits.
